# Jarvis — assistant vocal pour Windows

Dis **« Jarvis »** suivi d'une demande : clips OBS, musique, son, applis, questions… Pensé pour jouer.

## Installer

1. Télécharge **[Jarvis-Setup.exe](https://github.com/roblitchtv-dotcom/jarvis/releases/latest/download/Jarvis-Setup.exe)** (dernière version).
2. Lance-le. Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires → Exécuter quand même** (l'application n'est pas signée, c'est normal).
3. Suis l'installation (pas besoin d'être administrateur). Jarvis apparaît près de l'horloge.

Ensuite, dans **Réglages → Intelligence**, choisis l'IA : Claude (ton compte Claude), Gemini (gratuit, avec une clé Google) ou Locale (gratuite, sans compte).

## Mises à jour

Automatiques : quand une nouvelle version sort, Jarvis te la propose (bandeau dans l'appli + notification). Un clic sur **Installer** et c'est fait.

> Si tu as une version **1.3.0 ou plus ancienne**, réinstalle une fois avec le lien ci-dessus : les mises à jour automatiques fonctionneront ensuite.

## Exemples

« Jarvis, clip-moi ça » · « Jarvis, mets Someone You Loved » · « Jarvis, baisse le son de Discord » · « Jarvis, ouvre Discord » · « Jarvis, c'est quoi cette musique ? » · touche **F9** pour parler sans dire « Jarvis ».
